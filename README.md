# SportMaps

Android-приложение для поиска спортивных площадок Москвы, сбора составов и общения с игроками.
Kotlin, Jetpack Compose, Material 3, MVVM. Интерфейс полностью на русском.

## Как запустить
1. Установите свежую Android Studio (Ladybug 2024.2 или новее) с JDK 17 (идёт в комплекте).
2. File → Open → выберите папку SportMaps (ту, где лежит settings.gradle.kts).
3. Дождитесь Gradle Sync (нужен интернет при первой синхронизации). Если Studio предложит
   обновить Gradle / AGP — можно согласиться, проект от этого не сломается.
4. Выберите эмулятор (API 24+) или телефон и нажмите Run ▶.

## Структура
- data/ — модели, UserPreferences (SharedPreferences), репозитории (Auth, Grounds, Messages)
- ui/theme/ — цвета и светлая/тёмная тема
- ui/components/ — общие элементы и боковое меню
- ui/screens/ — экраны
- ui/viewmodel/ — ViewModel и фабрика
- ui/navigation/ — маршруты и граф навигации (по User Flow)
